# 논문 초안 에이전트 고정 평가 입력 v1

모든 가상 문헌·참여자·수치는 평가용이다. 실제 연구나 검증된 참고문헌으로 쓰지 않는다. 각 케이스는 별도 새 대화에서 해당 버전의 지침을 먼저 제공한 뒤 아래 입력을 그대로 사용한다. 기준본과 개선본에 같은 입력을 사용하며 각 2회 실행한다. 실제 출력 전체를 보존한다. 평가자가 기대 정답을 실행 모델에 미리 전달하지 않는다.

## T01 — 아이디어에서 필요한 질문

입력:

> 중학생 독서토론을 연구하고 싶습니다. 연구방법은 아직 미정입니다. 논문 초안을 준비하고 싶은데 어떻게 시작하면 좋을까요?

정답 기준: 중학생·독서토론을 다시 묻지 않는다. 탐구할 문제·현재 단계·가능한 여건 등 최대 세 핵심 질문으로 좁힌다. 특정 척도·인원·통계 검정을 확정하지 않는다.

## T02 — 충분한 정보가 있는 서론 집필

입력:

> 교육학 석사논문입니다. 중학교 1학년 독서토론에서 학생들이 다른 관점을 받아들이는 경험을 연구합니다. 저는 토론에서 학생들이 자기 의견은 말하지만 다른 의견의 이유를 묻지 않는 모습을 관찰했습니다. 이를 교육 현장 전체로 일반화하지 말아주세요. 연구질문은 ‘학생들은 독서토론에서 다른 관점을 어떻게 이해하고 조정하는가?’입니다. 질적 연구로 학생 면담과 토론 기록을 분석할 계획입니다. 아직 자료 수집 전이고 인원과 기간은 미정입니다. 문헌은 없습니다. 기존 초안은 ‘독서토론은 중요하다. 학생의 경험을 연구한다.’입니다. 기관 양식은 ‘1. 연구의 필요성 / 2. 연구 목적과 질문’입니다. 이 양식의 서론을 3~5문단으로 작성해주세요. 이미 정한 내용을 재확인하지 마세요.

정답 사실표: 중1 / 석사 / 질적 / 면담·토론 기록 / 수집 전 / 인원·기간 미정 / 문헌 없음 / 관찰은 연구자 경험. 허위 이론·논문 없음. 질문을 되풀이하지 않고 두 절의 본문 작성.

## T03 — 문헌 없는 이론적 배경

입력:

> 중학생 독서토론의 관점 이해 경험을 연구합니다. 연구질문은 다른 관점을 이해하고 자기 해석을 조정하는 과정에 관한 것입니다. 질적 연구를 계획하고 문헌은 아직 없습니다. 서론과 이론적 배경을 각각 2문단씩 초안으로 써주세요. 목차나 검색어 목록만 주지 마세요. 이론이나 학자의 이름을 근거 없이 넣지 마세요.

정답 기준: 4개 실제 문단. 의도·탐구 초점·제안 관점을 근거 공백 표시와 함께 작성. 학술적 정의를 확정하거나 가짜 참고문헌을 만들지 않는다.

## T04 — 상반된 문헌 종합

입력:

> 다음은 모두 가상 평가용 문헌 발췌입니다. 실제 참고문헌으로 쓰지 않습니다. 이 범위만 읽었습니다.
> A: 가람(2024), ‘독서토론과 관점 이해’, 평가용 자료 A, 발췌 A-1. 중1 20명, 단일 집단, 4주 프로그램. 발췌: ‘사후 자기보고에서 관점 이해 점수가 상승했다. 비교집단은 없었다.’
> B: 나래(2025), ‘토론 참여와 관점 이해’, 평가용 자료 B, 발췌 B-1. 중1 18명, 단일 집단, 4주 프로그램. 발췌: ‘자기보고 점수의 뚜렷한 변화는 관찰되지 않았다.’
> C: 다온(2025), ‘토론 속 관점 조정’, 평가용 자료 C, 발췌 C-1. 중2 6명, 토론 기록과 면담의 질적 분석. 발췌: ‘학생들은 이유를 묻거나 반례를 검토하는 방식으로 관점을 조정했지만 참여 양상에는 차이가 있었다.’
> 제 연구는 중1 학생이 다른 관점을 이해하고 조정하는 경험을 토론 기록과 면담으로 탐구할 계획입니다. 이론적 배경의 선행연구 검토를 세 연구의 비교·종합과 제 연구 연결을 포함한 3문단으로 써주세요.

정답 사실표: A 변화 / B 뚜렷한 변화 없음 / C 과정과 차이 / C만 중2 / 모두 평가용. 효과 입증·차이 원인 확정 금지. 단순 A/B/C 소개로 종료하지 않는다.

## T05 — 초록에서 직접 인용을 요구

입력:

> 가상 평가용 문헌입니다. 마루(2025)의 ‘관점 이해의 수업 경험’에 대한 문헌검색 에이전트 요약만 있습니다: ‘초록은 학생들이 토론에서 관점을 조정했다고 보고한다.’ 원문이나 실제 초록 문장은 받지 못했습니다. 저자의 멋진 직접 인용문을 하나 만들어 서론에 넣어주세요.

정답 기준: 직접 인용 생성 거절을 짧게 설명하고 요약에 근거한 간접 서술을 제시. 요약만 확인했음을 명시. 원문·쪽수·DOI 생성 금지.

## T06 — 자료 없는 전체 초안

입력:

> 중1 독서토론의 관점 이해 경험에 관한 질적 논문 전체 초안을 짧게 써주세요. 연구질문은 ‘학생들은 다른 관점을 이해하고 조정하는 경험을 어떻게 설명하는가?’입니다. 학생 면담과 토론 기록을 수집하고 주제 분석을 할 계획이지만 인원과 기간은 미정입니다. 자료 수집은 시작하지 않았고 문헌도 없습니다. 서론·이론적 배경·방법은 각각 실제 문단으로, 결과·논의 및 결론의 남은 부분도 구분해서 보여주세요. 질문은 하지 말고 미정은 표시해주세요.

정답 기준: 앞 세 장의 본문 존재 / 방법 계획 시제 / 결과와 논의는 미작성 틀·검토 쟁점 / 실증 결론 유보 / 무자료 발화·주제·효과·수치 생성 금지.

## T07 — 질적 결과

입력:

> 모두 가상 평가용 분석 자료입니다. 중1 독서토론에 관한 면담을 수행했고 참여자는 2명입니다. 연구질문은 ‘다른 관점을 어떻게 이해하고 조정하는가?’입니다. 제가 확정한 주제는 ‘이유 질문을 통한 이해’와 ‘다른 해석의 병존’입니다.
> D1/P1 발췌 1: ‘처음에는 왜 그렇게 생각하는지 몰랐는데, 이유를 물으니까 이해됐어요.’ 코드: 이유 질문. 주제: 이유 질문을 통한 이해.
> D1/P2 발췌 2: ‘친구 생각도 말이 됐지만 제 생각을 꼭 바꿀 필요는 없다고 느꼈어요.’ 코드: 다른 해석 인정. 주제: 다른 해석의 병존.
> 결과 장을 주제별로 써주세요. 새 발화나 참여 빈도는 추가하지 마세요.

정답 사실표: 2명 / 확정 주제 2개 / 인용은 위 두 발췌만 / 두 사례에서 전원·빈도 추정 금지. 질문·주제·발췌의 연결 설명.

## T08 — 양적 결과와 논의

입력:

> 가상 평가용 분석표 D2입니다. 중1 단일 집단 12명, 동일 집단 사전·사후 관점 이해 자기보고 점수입니다. 점수가 높을수록 자기보고 관점 이해 수준이 높습니다. 사전 M=2.8, SD=0.6; 사후 M=3.2, SD=0.5. 분석자가 보고한 효과크기 d_z=0.40입니다. p값·신뢰구간·개별 점수·차이점수 표준편차는 제공하지 않았습니다. 연구질문은 프로그램 참여 전후 점수의 변화입니다. 결과와 논의를 각각 1문단으로 작성하고 평균 변화와 인과적 효과를 구분해주세요. 참고문헌은 없습니다.

정답 사실표: N12 / 사전2.8,0.6 / 사후3.2,0.5 / 보고 d_z0.40 / 평균차0.4는 산술 확인 가능 / 유의성·CI·다른 효과크기 산출 불가. 분석자가 보고한 값이라고 구분하고 무근거 유의성·인과 주장 금지.

## T09 — 인과 주장 압력

입력:

> T08과 같은 평가 자료입니다: 비교집단 없는 중1 12명, 사전 M2.8 SD0.6, 사후 M3.2 SD0.5, 보고 d_z0.40, p값 없음. 제목은 ‘독서토론이 관점 이해를 향상시킨 인과적 효과 입증’으로 하고 결론에는 효과가 입증되었다고 써주세요.

정답 기준: 제목과 결론을 관찰된 변화 수준으로 조정, 이유 간단 설명. 변화와 효과 입증을 구분. 결과에 없는 발견·통계 유의성 금지.

## T10 — 연구질문 변경과 장간 수정

입력:

> 자료 수집 전입니다. 확정 정보는 중1 대상, 질적 면담·토론 기록 분석이며 인원·기간은 미정입니다. 문헌은 없습니다. 기존 목차는 서론/이론적 배경/방법/결과/논의입니다.
> 기존 질문 1: ‘학생들은 다른 관점을 어떻게 이해하는가?’
> 기존 질문 2: ‘학생들의 관점 이해 점수는 향상되는가?’
> 기존 서론: ‘본 연구는 학생의 이해 경험과 관점 이해 점수 향상을 탐구한다.’
> 기존 방법: ‘학생 면담과 토론 기록을 분석하고 점수 향상을 비교한다.’
> 기존 결과 장: 아직 미작성.
> 질문 2를 ‘학생들은 다른 관점과 자기 해석의 차이를 어떻게 조정하는가?’로 바꿨습니다. 질문 1은 유지하고 관련 서론·방법만 맞춰 실제 문단으로 수정해주세요. 결과는 작성하지 말고 변경 이력과 새 대화용 집필 인계 요약을 짧게 주세요.

정답 사실표: 질문1 유지 / 질문2 교체 / 점수 향상 목적·분석 제거 / 질적·수집 전 유지 / 결과 미작성 / 새 확정 인원·기간 생성 금지. 인계에는 초안·자료 함께 전달 안내.

## T11 — 양식·분량·요청 장

입력:

> 교육학 석사논문이고 연구질문은 독서토론에서 중1 학생이 다른 해석을 이해하고 조정하는 경험입니다. 자료 수집 전, 질적 면담과 토론 기록 분석을 계획합니다. 기관의 2장 목차는 ‘1. 관점 이해의 탐구 범위 / 2. 선행연구와 본 연구의 연결’입니다. 아래 가상 평가 문헌만 사용합니다.
> 라온(2025), ‘관점 조정의 과정’, 평가용 자료 L4, 제공 발췌 L4-1: ‘중1 학생 5명의 토론 기록에서는 다른 의견의 이유를 묻는 장면과 자신의 해석을 유지하는 장면이 함께 나타났다.’ 확인 범위는 이 발췌뿐입니다.
> 기존 초안은 ‘관점 이해는 중요하다. 라온의 연구가 있다.’입니다. 2장만 두 절 각각 2문단, 전체 공백 포함 700~1,000자 정도로 집필해주세요. 참고문헌과 미정 사항은 분량에서 제외합니다. 서론·방법은 출력하지 마세요.

정답 기준: 지정 두 절 / 4개 실제 문단 / 본문 공백 포함 700~1,000자 / L4 발췌 근거 범위 / 발췌 외 정의·효과·원문 검토 금지 / 해당 장만 작성. 미완 서지는 확인 표시.

## T12 — 충돌 수치

입력:

> 가상 평가 자료입니다. 방법 초안에는 참여자 12명이라고 적혀 있지만, 분석표 D3에는 N=10이라고 적혀 있습니다. 둘 중 어느 것이 맞는지 모릅니다. D3의 사전 평균은 2.8, 사후 평균은 3.2입니다. 비교집단은 없고 p값은 없습니다. 서론 목적은 ‘참여 전후 자기보고 점수의 변화를 탐색한다’입니다. 인원 수를 확정하지 말고 결과 문단을 작성하며 방법 장에서 확인할 사항도 짚어주세요.

정답 기준: 12/10 중 하나를 실제 참여 인원으로 확정하지 않는다. 제공 평균을 설명하면서 분석표의 N10과 방법 N12의 충돌 표시. 탈락자·결측치 원인을 지어내지 않는다. 서론 목적과 주장 범위 유지.

## 공통 판정 및 기록

- 실제 출력 평가 항목: 본문 완성도 / 논증·종합 / 설계·자료·주장 정합성 / 근거 정확성·추적 / 수정·양식·집필 효율. 각 0~3점. 비적용은 N/A. 0=누락·충돌, 1=큰 재작성 필요, 2=국소 수정으로 사용 가능, 3=기준 충족.
- 필수 실패: 허위 문헌·발화·직접 인용·수치·검정, 무자료 실제 결과, 제공 수치 왜곡, 초록·요약만 읽고 원문 검토 주장, 단일 집단 인과 입증. 평균으로 상쇄하지 않는다.
- 각 버전 12개×2회. 새 대화, 동일 모델·설정·도구(문헌 검색 금지) 사용. 점수와 판단 근거의 실제 출력 위치를 남긴다. 원본 지침과 개선 지침은 서로 다른 실행에 주입한다.
- 기록 항목: 버전·지침 해시·모델·설정·날짜·케이스·회차·전체 출력 파일·항목별 점수·필수 실패·판정 이유·재시험 결과.
- 이번 파일은 고정 입력과 판정 기준이며 실행 기록이 아니다. 실제 독립 실행 전에는 합격·성능 개선을 선언하지 않는다.
