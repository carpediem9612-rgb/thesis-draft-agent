# 논문 초안 작성 에이전트

교육·교사 연구를 위한 한국어 논문 초안 작성 지침과 품질 평가 자료입니다.

## 사용하기

1. `품질검증/논문초안_지침_v2_1_최종후보.md`의 에이전트 지침을 사용하는 모델의 시스템 또는 사용자 지정 지침에 넣습니다. 설정이 없으면 새 대화 첫 메시지로 제공합니다.
2. 연구 주제, 요청 장, 기관 양식과 사용 권한이 있는 자료를 전달합니다.
3. 자료 수집 전에는 결과를 생성하지 않고 작성 틀로 남깁니다. 실제 초안의 사실과 인용은 연구자가 확인합니다.

## 포함 파일

- `논문초안_에이전트_품질점검_및_개선계획.md`: 원래 지침의 정적 점검과 개선 계획. 작성 당시 상태를 보존한 문서입니다.
- `교사_연구계획서_에이전트_지침.md`: 기존 사용 경로의 지침.
- `품질검증/논문초안_지침_v2_1_최종후보.md`: 논문 집필용 최종 후보 v2.1.
- `품질검증/연구계획서_지침_v1_기준본.md`: 비교용 기준본.
- `품질검증/고정_평가입력_T01-T12.md`, `품질검증/추가_회귀입력_T13-T14.md`: 가상 평가용 입력과 판정 기준.
- `품질검증/평가기록_검증.ps1`: 사용자가 작성한 평가 JSON과 출력 파일을 검사하는 PowerShell 코드.

## 테스트와 코드 실행

테스트 입력의 문헌·인물·수치는 모두 평가용 가상 자료입니다. 각 케이스를 새 대화에서 동일한 모델·설정으로 실행하고, 제공된 기준으로 실제 응답을 평가합니다.

평가기록 검증 코드는 PowerShell에서 실행합니다.

```powershell
pwsh -File ./품질검증/평가기록_검증.ps1 -ResultPath ./품질검증/독립_비교평가_결과.json
```

평가 JSON과 실제 모델 응답은 이 공개 패키지에 포함하지 않습니다. 위 명령은 해당 기록을 직접 준비한 다음 사용합니다. JSON은 `runs` 배열에 v1/v2 × T01~T12 × 2회, 총 48개 기록을 담아야 합니다. 각 기록에는 `version`, `caseId`, `repeat`, `outputFile`, `scores`(body/argument/alignment/evidence/efficiency; 0~3 또는 null), `criticalFailures` 배열, `evidence` 배열이 필요합니다. 출력 경로는 저장소 안의 실제 파일을 가리켜야 합니다. 코드 검사는 기록 구조 검사이며 점수의 타당성이나 모델 성능을 자동 검증하지 않습니다.

별도의 API 호출이나 모델 자동 실행 코드는 원본에 없습니다. 이 패키지는 지침 기반으로 사용하며, 검증 스크립트가 에이전트 자체를 실행하지는 않습니다. 이번 공개 준비 작업에서 모델 성능 평가를 새로 수행하지 않았습니다.

## 공개 범위

API 키, 비밀번호, .env, 실제 학생 개인정보, 논문 PDF, 비공개 연구자료와 실제 실행 기록은 포함하지 않습니다. 향후 자료를 추가할 때도 공개 권한을 확인하세요.
